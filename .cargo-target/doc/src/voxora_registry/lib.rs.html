1//! Central model registry for voxora (ASR-specific).
2//!
3//! Owns the answer to "given a model id, give me the engine + the
4//! exact on-disk file". Before this crate existed, that answer was
5//! distributed across `voxora-hf` (cache key), `voxora-whisper`
6//! (lex-sort over `*.bin`), and `voxora-cli` (heuristic). Now it
7//! lives here.
8//!
9//! ## Phase 0 surface
10//!
11//! - [`ModelId::parse`] — strict parser for `org/repo` /
12//!   `org/repo/file` / `/local/path` / `./local-path`.
13//! - [`Registry`] — a list of [`EngineDescriptor`]s + a
14//!   [`voxora_traits::ModelSource`] used to download/locate the model.
15//! - [`builtin_whisper_descriptor`] / [`builtin_qwen3asr_descriptor`]
16//!   — default descriptors. `Registry::with_builtin_descriptors()` is
17//!   provided by the `RegistryHfExt` trait behind the `hf` feature.
18//! - [`CacheManifest`] — `.voxora-manifest.json` written next to
19//!   cached weights so future runs can answer "which engine?" without
20//!   re-parsing the directory.
21//!
22//! ASR-specific: the descriptors model only ASR engines (Whisper,
23//! Qwen3-Asr). Adding `parakeet`, `voxtral`, or `granite-speech` is
24//! a 0.2.x change.
