Expand description

A source of models (Hugging Face, a local directory, future registries).

Acquisition is inherently asynchronous (network downloads), so this trait uses async_trait even though crate::AsrEngine is sync. The trait requires Send + Sync so a Box<dyn ModelSource> can move across thread boundaries inside an HTTP server or CLI.
