The AsrEngine trait and the value types that travel through it.

An AsrEngine wraps a single ASR backend (whisper.cpp, qwen3-asr, future engines) behind a synchronous, Send + Sync interface so any caller can hold an Arc<dyn AsrEngine> and swap implementations without touching inference code.
